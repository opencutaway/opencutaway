# Content

This directory holds **schema examples, UI contracts, and playable sitting copy**.

- `examples/` — valid instances of catalog schemas under `/schema` (not a filled catalog)
- `ui/` — player-facing UI contracts validated with Ajv
- `sittings/` — widen sitting 1–2 copy and hotspots (Cross the Street, Lights). Kid-facing sentences still require the human gate in `/workflows`

Future object JSON must pass `workflows/content-authoring.example.yaml`, including the human gate for kid-facing copy.
